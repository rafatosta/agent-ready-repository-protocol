# Mapa de documentação

Use este arquivo como roteador. Não leia toda a documentação por padrão.

| Se a tarefa afetar... | Consulte primeiro... | Contexto adicional possível |
|---|---|---|
| objetivo/escopo do produto | `project-context.md` | documentação de usuário |
| interpretação/planejamento | `task-protocol.md` | `model-policy.md` |
| arquitetura/dependências | `architecture.md` | decisões de mantenedores |
| domínio/regras | `domain.md` | fonte normativa/especificação |
| implementação | `coding-rules.md` | arquivos da área |
| testes | `testing.md` | configuração de CI |
| commit/finalização | `workflow-rules.md`, `commit-convention.md` | changelog |
| decisão estrutural | `decision-policy.md` | ADRs/histórico |

## Documentação específica do projeto

Adicione linhas para UI/UX, API, segurança, banco, normativa, deployment ou qualquer área relevante.

## Histórico

Documentos históricos não fazem parte do contexto inicial salvo quando a tarefa exige investigar a origem de uma decisão.
