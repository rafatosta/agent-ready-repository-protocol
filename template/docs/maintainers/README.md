# Documentação para mantenedores

Esta pasta é destinada a pessoas que mantêm o projeto. Pode conter:

- ADRs e decisões arquiteturais;
- processo de desenvolvimento e revisão;
- estratégia de releases;
- histórico de grandes migrações;
- operação e manutenção;
- decisões de produto.

Esse conteúdo não deve ser leitura automática do agente. `docs/ai/documentation-map.md` aponta para documentos daqui somente quando forem necessários para a tarefa.
