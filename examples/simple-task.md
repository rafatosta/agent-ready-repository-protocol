# Exemplo — tarefa simples

## Solicitação

```text
Mova as ações secundárias do cabeçalho para um menu de opções.
```

## Interpretação esperada

- tarefa localizada;
- contexto principal: UI/UX e componente do cabeçalho;
- não há motivo inicial para carregar domínio, banco ou histórico;
- modelo/capacidade leve ou intermediário provavelmente é suficiente.

## Fluxo

```text
AGENTS.md
→ task-protocol
→ mapa de documentação
→ UI/UX relevante
→ componente + testes relacionados
→ implementação
→ validação
→ changelog/documentação se aplicável
→ commit
```

O agente não precisa transformar essa solicitação em um prompt extenso.
