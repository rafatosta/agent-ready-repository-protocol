# Convenção de commits

## Formato

Defina aqui a convenção adotada pelo projeto.

Exemplo com Conventional Commits:

```text
type(scope): descrição
```

## Tipos

- `feat`: [política]
- `fix`: [política]
- `refactor`: [política]
- `docs`: [política]
- `test`: [política]
- `chore`: [política]

## Regras

- um commit por unidade lógica quando a tarefa for composta;
- mensagem deve descrever o efeito da alteração;
- corpo opcional explica decisões não evidentes;
- não misturar mudanças independentes;
- seguir o idioma definido pelo projeto.

## Autorização

Declare se o agente pode criar commits locais automaticamente. Push e demais ações externas devem ter política separada.
